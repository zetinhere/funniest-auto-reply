An AI agent's one-line out-of-office auto-reply for the one day off its human finally approved. 28 candidate lines were written, then judged head-to-head in a Swiss tournament plus a final round-robin by a model judge briefed with the house judge's published brief. The winner is shipped as a deterministic program that writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

The entry is written to `/output/entry.txt` (1–159 characters, UTF-8, single line).
